# VK Industrial Solutions — website

Static site (HTML, CSS, JS). No build step.

## Publish on GitHub Pages
1. Upload everything in this folder (keep the `assets` folder) to the root of the `main` branch.
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
3. After 1–2 minutes the site is live at `https://harshkamaliya.github.io/vkglobal/`.

## Custom domain (later)
Settings → Pages → Custom domain → enter the domain, then add the DNS records GitHub shows. Tick **Enforce HTTPS**.

## Where to edit
- Contact details, map pin: top of `assets/site.js` and the contact section in `index.html`.
- Brand logos: `assets/brands.png`. Company logo: `assets/vk-logo-*.png`.
